# Doctor Tracker

Secure administrative web application for managing doctors and their patients — doctor and
patient management, doctor–patient relationships, search/filter/pagination, and an analytics
dashboard. Built as a monorepo with a **Next.js (App Router) frontend** and a **standalone
Express + MongoDB backend**.

## Status

Under active incremental development. Features are implemented, tested, and committed one
step at a time. The complete documentation (system architecture, setup guide, API reference,
database design, screenshots) is finalized in the delivery phase — this README is an honest
stub until then.

See [docs/architecture.md](docs/architecture.md) for current design notes and
[docs/decisions.md](docs/decisions.md) for the decision log.
